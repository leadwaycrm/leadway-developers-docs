Retrieve a list of LinkedIn campaigns or campaign groups with reporting data

```http
GET https://services.leadconnectorhq.com/ad-publishing/linkedin/reporting/list
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required>
Account ID
</ParamField>

<ParamField query="listType" type="string" required>
List type
</ParamField>

<ParamField query="campaignId" type="string" required>
Campaign ID
</ParamField>

<ParamField query="campaignGroupId" type="string" required>
Campaign group ID
</ParamField>

<ParamField query="startDate" type="string" required default='2024-01-01'>
Start date in yyyy-mm-dd format
</ParamField>

<ParamField query="endDate" type="string" required default='2024-01-31'>
End date in yyyy-mm-dd format
</ParamField>

<ParamField query="fields" type="string[]">
Comma-separated list of fields to retrieve
</ParamField>
