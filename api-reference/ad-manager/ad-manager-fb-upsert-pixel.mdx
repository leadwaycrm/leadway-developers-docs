Create or update a Facebook conversion pixel configuration

```http
PUT https://services.leadconnectorhq.com/ad-publishing/facebook/pixels
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="conversionPixelId" type="string" default='px_123'>
Conversion pixel ID
</ParamField>

<ParamField body="name" type="string" default='My Pixel'>
Pixel name
</ParamField>

<ParamField body="igUserId" type="string" default='ig_user_123'>
Instagram user ID
</ParamField>

<ParamField body="type" type="string" required default='LEAD_EVENT'>
Pixel event type
</ParamField>
