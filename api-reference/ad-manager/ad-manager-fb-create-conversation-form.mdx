Create a new Facebook conversation lead form

```http
POST https://services.leadconnectorhq.com/ad-publishing/facebook/conversation-forms
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="name" type="string" required default='Welcome Form'>
Conversation form name
</ParamField>

<ParamField body="text" type="string" required default='Hi! How can we help?'>
Welcome message text
</ParamField>

<ParamField body="questions" type="object[]" required>
Quick-reply questions shown in the welcome message of the conversation form
<Expandable title="cada item">
<ParamField body="question" type="string" required default='How can we help?'>
Question title text
</ParamField>

<ParamField body="response" type="string" default='Thanks for reaching out'>
Auto-response message
</ParamField>

</Expandable>
</ParamField>
