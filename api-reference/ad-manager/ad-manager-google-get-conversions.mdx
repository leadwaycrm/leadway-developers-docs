Retrieve Google Ads conversion actions for a account

```http
GET https://services.leadconnectorhq.com/ad-publishing/google/conversions
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField query="type" type="string" default='AD_MANAGER'>
Integration type
</ParamField>

<ParamField query="conversionType" type="string" default='WEBPAGE'>
Conversion type
</ParamField>

<ParamField query="category" type="string" default='PURCHASE'>
Conversion category
</ParamField>

<ParamField query="startDate" type="string" default='2024-01-01'>
Filter start date
</ParamField>

<ParamField query="endDate" type="string" default='2024-12-31'>
Filter end date
</ParamField>
