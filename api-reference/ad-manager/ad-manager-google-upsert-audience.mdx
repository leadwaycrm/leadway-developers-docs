Create or update a Google Ads combined audience

```http
PUT https://services.leadconnectorhq.com/ad-publishing/google/audiences
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="resourceName" type="string" default='customers/123/audiences/456'>
Audience resource name
</ParamField>

<ParamField body="name" type="string" required default='My Audience'>
Audience name
</ParamField>

<ParamField body="dimensions" type="object">
Audience dimensions
</ParamField>

<ParamField body="exclusionDimension" type="object">
Exclusion dimensions
</ParamField>
