Add a member to a Facebook custom audience

```http
PUT https://services.leadconnectorhq.com/ad-publishing/facebook/custom-audience/{audienceId}/member
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="audienceId" type="string" required default='23851234567890123'>
Custom audience identifier
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="contactId" type="string" required default='contact_123'>
Contact identifier
</ParamField>

<ParamField body="fbAdAccountId" type="string" default='act_123456'>
Facebook ad account ID
</ParamField>
