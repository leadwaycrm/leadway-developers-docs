Retrieve Google campaigns, ad groups, or ads based on entity type

```http
GET https://services.leadconnectorhq.com/ad-publishing/google/entity
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField query="type" type="string" required default='AD_MANAGER'>
Integration type
</ParamField>

<ParamField query="campaignId" type="string" default='camp_123'>
Campaign identifier
</ParamField>

<ParamField query="adGroupId" type="string" default='ag_123'>
Ad group identifier
</ParamField>

<ParamField query="entityType" type="string" required default='CAMPAIGN'>
Entity type
</ParamField>

<ParamField query="searchId" type="string" default='search_123'>
Search identifier
</ParamField>

<ParamField query="startDate" type="string" default='2024-01-01'>
Filter start date
</ParamField>

<ParamField query="endDate" type="string" default='2024-12-31'>
Filter end date
</ParamField>

Selected ad account ID
</ParamField>
