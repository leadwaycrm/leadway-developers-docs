Create a Facebook ad integration for a account with page and ad account

```http
POST https://services.leadconnectorhq.com/ad-publishing/facebook/integration
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="pageId" type="string" required default='123456789'>
Facebook page ID
</ParamField>

<ParamField body="adAccountId" type="string" default='act_123456'>
Ad account identifier
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X POST 'https://services.leadconnectorhq.com/ad-publishing/facebook/integration' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "locationId": "loc_abc123",
  "pageId": "123456789",
  "adAccountId": "act_123456"
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/ad-publishing/facebook/integration', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({"locationId": "loc_abc123", "pageId": "123456789", "adAccountId": "act_123456"}),
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'POST',
    'https://services.leadconnectorhq.com/ad-publishing/facebook/integration',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
        'Content-Type': 'application/json',
    },
    json={"locationId": "loc_abc123", "pageId": "123456789", "adAccountId": "act_123456"},
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/ad-publishing/facebook/integration');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'POST',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode({'locationId': 'loc_abc123', 'pageId': '123456789', 'adAccountId': 'act_123456'}),
]);
$data = json_decode(curl_exec($ch), true);
```
