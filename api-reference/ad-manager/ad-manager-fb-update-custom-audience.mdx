Update name or description of a Facebook custom audience

```http
PUT https://services.leadconnectorhq.com/ad-publishing/facebook/custom-audience/{audienceId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="audienceId" type="string" required default='23851234567890123'>
Custom audience identifier
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='HChooFuiyPpVYzeJ4HMe'>
Account identifier
</ParamField>

<ParamField body="name" type="string" required default='My Custom Audience'>
Audience name
</ParamField>

<ParamField body="description" type="string" required default='Lookalike audience from website visitors'>
Audience description
</ParamField>
