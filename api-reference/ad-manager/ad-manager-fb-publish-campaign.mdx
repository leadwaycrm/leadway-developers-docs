Publish a Facebook campaign and push it live to Facebook

```http
POST https://services.leadconnectorhq.com/ad-publishing/facebook/campaigns/{campaignId}/publish
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="campaignId" type="string" required default='120208142050850608'>
Campaign identifier
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X POST 'https://services.leadconnectorhq.com/ad-publishing/facebook/campaigns/YOUR_campaignId/publish' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "locationId": "loc_abc123"
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/ad-publishing/facebook/campaigns/YOUR_campaignId/publish', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({"locationId": "loc_abc123"}),
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'POST',
    'https://services.leadconnectorhq.com/ad-publishing/facebook/campaigns/YOUR_campaignId/publish',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
        'Content-Type': 'application/json',
    },
    json={"locationId": "loc_abc123"},
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/ad-publishing/facebook/campaigns/YOUR_campaignId/publish');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'POST',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode({'locationId': 'loc_abc123'}),
]);
$data = json_decode(curl_exec($ch), true);
```
