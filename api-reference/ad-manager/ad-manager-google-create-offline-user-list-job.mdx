Create a job to upload users to a Google customer match list

```http
POST https://services.leadconnectorhq.com/ad-publishing/google/segments/offline-user-list-job
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField body="smartListIds" type="string[]">
Smart list IDs
</ParamField>

<ParamField body="csvPath" type="string" default='/uploads/users.csv'>
CSV file path
</ParamField>

<ParamField body="userListId" type="string" default='ul_123'>
User list identifier
</ParamField>

<ParamField body="isDynamic" type="boolean" default='False'>
Dynamic list flag
</ParamField>
