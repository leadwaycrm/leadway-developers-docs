Retrieve reporting metrics for a specific Google campaign

```http
GET https://services.leadconnectorhq.com/ad-publishing/google/reporting/campaign/{campaignId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="campaignId" type="string" required default='camp_abc123'>
Campaign identifier
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='fRMewNQIxSyZ5R4nQyit'>
Account identifier
</ParamField>

<ParamField query="startDate" type="string" required default='2022-01-11'>
Report start date
</ParamField>

<ParamField query="endDate" type="string" required default='2022-01-31'>
Report end date
</ParamField>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/ad-publishing/google/reporting/campaign/YOUR_campaignId', {
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/ad-publishing/google/reporting/campaign/YOUR_campaignId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/ad-publishing/google/reporting/campaign/YOUR_campaignId');

    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',

        'Version: 2021-07-28',
    ],
]);
```
