Retrieve keyword suggestions for Google Ads campaigns

```http
POST https://services.leadconnectorhq.com/ad-publishing/google/keyword-ideas
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='HChooFuiyPpVYzeJ4HMe'>
Account identifier
</ParamField>

## Body

<ParamField body="url" type="string" required default='https://example.com'>
Target URL
</ParamField>

<ParamField body="languageCode" type="string" default='en'>
Language code
</ParamField>

<ParamField body="locations" type="string[]">
Target accounts
</ParamField>

<ParamField body="keywords" type="string[]">
Seed keywords
</ParamField>
