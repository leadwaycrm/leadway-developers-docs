Pause or resume a LinkedIn ad, campaign, or ad group

```http
PATCH https://services.leadconnectorhq.com/ad-publishing/linkedin/{adId}/status
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="adId" type="string" required default='507f1f77bcf86cd799439011'>
Ad identifier
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='HChooFuiyPpVYzeJ4HMe'>
Account identifier
</ParamField>

## Body

<ParamField body="operationType" type="string" required default='PAUSED'>
Update operation Posibles valores: 'PAUSED', 'ARCHIVED', 'RESUME'
</ParamField>

<ParamField body="type" type="string" required default='adCampaign'>
Ad object type Posibles valores: 'adGroup', 'adCampaign', 'ad'
</ParamField>
