Retrieve Facebook custom audiences for a account

```http
GET https://services.leadconnectorhq.com/ad-publishing/facebook/custom-audience
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField query="type" type="string" required default='custom'>
Audience list type
</ParamField>

<ParamField query="source" type="string" default='ad_manager'>
Audience data source
</ParamField>

<ParamField query="adAccountId" type="string" required default='act_123456'>
Ad account identifier
</ParamField>
