Create a LinkedIn Ads integration for a account with ad account details

```http
POST https://services.leadconnectorhq.com/ad-publishing/linkedin/integration
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='loc_123'>
Account identifier
</ParamField>

<ParamField body="adAccountId" type="string" required default='12345678'>
Ad account identifier
</ParamField>

<ParamField body="adAccountName" type="string" required default='My Ad Account'>
Ad account name
</ParamField>

<ParamField body="currencyCode" type="string" required default='USD'>
Currency code
</ParamField>

<ParamField body="organizationId" type="string" required default='12345678'>
Organization identifier
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X POST 'https://services.leadconnectorhq.com/ad-publishing/linkedin/integration' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "locationId": "loc_123",
  "adAccountId": "12345678",
  "adAccountName": "My Ad Account",
  "currencyCode": "USD",
  "organizationId": "12345678"
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/ad-publishing/linkedin/integration', {

    Version: '2021-07-28',
```

```python Python
import os, requests
response = requests.request(

```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/ad-publishing/linkedin/integration');
```
