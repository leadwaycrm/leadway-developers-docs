Retrieve a Facebook campaign with its linked adsets and ads

```http
GET https://services.leadconnectorhq.com/ad-publishing/facebook/campaign/{campaignId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="campaignId" type="string" required default='120208142050850608'>
Campaign identifier
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='loc_abc123'>
Account identifier
</ParamField>

<ParamField query="fields" type="string" default='adsets,ads'>
Comma-separated field names
</ParamField>

<ParamField query="source" type="string" default='facebook'>
Campaign data source
</ParamField>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/ad-publishing/facebook/campaign/YOUR_campaignId', {
```

```python Python
import os, requests
response = requests.request(

    'https://services.leadconnectorhq.com/ad-publishing/facebook/campaign/YOUR_campaignId',

        'Version': '2021-07-28',

)

```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/ad-publishing/facebook/campaign/YOUR_campaignId');
```
