Publish a LinkedIn ad campaign group and push it live

```http
POST https://services.leadconnectorhq.com/ad-publishing/linkedin/ads/{adId}/publish
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="adId" type="string" required default='507f1f77bcf86cd799439011'>
Ad identifier
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='HChooFuiyPpVYzeJ4HMe'>
Account identifier
</ParamField>
