Add/Remove Contacts From Business . Passing a `null` businessId will remove the businessId from the contacts

```http
POST https://services.leadconnectorhq.com/contacts/bulk/business
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='PX8m5VwxEbcpFlzYEPVG'>
</ParamField>

<ParamField body="ids" type="string[]" required>
</ParamField>

<ParamField body="businessId" type="string" required default='63b7ec34ea409a9a8bd2a4ff'>
</ParamField>

## Respuestas

<Accordion title="200 - Successful response">
<ResponseField name="success" type="boolean" required default='True'>
</ResponseField>

<ResponseField name="ids" type="string[]" required>
</ResponseField>

```json
{
  "success": true,
  "ids": [
    "pOC0uJ97VYOKH2m3fkMD"
  ]
}
```
</Accordion>

<Accordion title="422 - Unprocessable Entity">
```json
{}
```
</Accordion>
