Get All Notes

```http
GET https://services.leadconnectorhq.com/contacts/{contactId}/notes
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="contactId" type="string" required default='sx6wyHhbFdRXh302LLNR'>
Contact Id
</ParamField>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/contacts/YOUR_contactId/notes', {
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/contacts/YOUR_contactId/notes',

        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/contacts/YOUR_contactId/notes');

    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
