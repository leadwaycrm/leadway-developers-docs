Get all Tasks

```http
GET https://services.leadconnectorhq.com/contacts/{contactId}/tasks
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="contactId" type="string" required default='sx6wyHhbFdRXh302LLNR'>
Contact Id
</ParamField>

<CodeGroup>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/contacts/YOUR_contactId/tasks', {

    Version: '2021-07-28',
  },

```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/contacts/YOUR_contactId/tasks',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/contacts/YOUR_contactId/tasks');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
