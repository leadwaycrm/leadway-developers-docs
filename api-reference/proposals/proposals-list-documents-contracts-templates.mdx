List document contract templates for a account

```http
GET https://services.leadconnectorhq.com/proposals/templates
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='jhg64gjhb436fv'>
Account Id
</ParamField>

<ParamField query="dateFrom" type="string" default='2025-02-03T18:30:00.000Z'>
Date start from (ISO 8601)
</ParamField>

<ParamField query="dateTo" type="string" default='2025-02-14T18:29:59.999Z'>
Date to (ISO 8601)
</ParamField>

<ParamField query="type" type="string" default='proposal,estimate'>
Comma-separated template types. Valid values: proposal, estimate, contentLibrary
</ParamField>

<ParamField query="name" type="string" default='Template Name'>
Template Name
</ParamField>

<ParamField query="isPublicDocument" type="boolean" default='False'>
If the docForm is a DocForm
</ParamField>

<ParamField query="userId" type="string" default='1234567890'>
User Id, required when isPublicDocument is true
</ParamField>

<ParamField query="limit" type="string" default='10'>
Limit
</ParamField>

<ParamField query="skip" type="string" default='0'>
Skip
</ParamField>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/proposals/templates', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },

```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/proposals/templates',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/proposals/templates');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
