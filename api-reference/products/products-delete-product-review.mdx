Delete specific product review

```http
DELETE https://services.leadconnectorhq.com/products/reviews/{reviewId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="reviewId" type="string" required default='6578278e879ad2646715ba9c'>
Review Id
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField query="altType" type="string" required>
</ParamField>

<ParamField query="productId" type="string" required default='6578278e879ad2646715ba9c'>
Product Id of the product
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X DELETE 'https://services.leadconnectorhq.com/products/reviews/YOUR_reviewId' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/products/reviews/YOUR_reviewId', {
  method: 'DELETE',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'DELETE',
    'https://services.leadconnectorhq.com/products/reviews/YOUR_reviewId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/products/reviews/YOUR_reviewId');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
