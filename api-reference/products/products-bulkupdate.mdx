API to bulk update products (price, availability, collections, delete)

```http
POST https://services.leadconnectorhq.com/products/bulk-update
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField body="altType" type="string" required>
Posibles valores: 'account'
</ParamField>

<ParamField body="type" type="string" required default='bulk-update-price'>
Type of bulk update operation Posibles valores: 'bulk-update-price', 'bulk-update-availability', 'bulk-update-product-collection', 'bulk-delete-products', 'bulk-update-currency'
</ParamField>

<ParamField body="productIds" type="string[]" required>
Array of product IDs
</ParamField>

<ParamField body="filters" type="object">
Filters to apply when selectAll is true
</ParamField>

<ParamField body="price" type="object">
Price update configuration
</ParamField>

<ParamField body="compareAtPrice" type="object">
Compare at price update configuration
</ParamField>

<ParamField body="availability" type="boolean">
New availability status
</ParamField>

<ParamField body="collectionIds" type="string[]">
Array of collection IDs
</ParamField>

<ParamField body="currency" type="string" default='USD'>
Currency code
</ParamField>
