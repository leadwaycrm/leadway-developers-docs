Create a new Product Collection for a specific account

```http
POST https://services.leadconnectorhq.com/products/collections
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id
</ParamField>

<ParamField body="altType" type="string" required default='LOCATION'>
The type of alt. For now it is only LOCATION Posibles valores: 'account'
</ParamField>

<ParamField body="collectionId" type="string" default='66057f9d28536eae584ec047'>
Unique Identifier of the Product Collection, Mongo Id
</ParamField>

<ParamField body="name" type="string" required default='Best Sellers'>
Name of the Product Collection
</ParamField>

<ParamField body="slug" type="string" required default='best-sellers'>
Slug of the Product Collection which helps in navigation
</ParamField>

<ParamField body="image" type="string" default='http://example.com/watermark.png'>
The URL of the image that is going to be displayed as the collection Thumbnail
</ParamField>

<ParamField body="seo" type="object">
The metadata information which will be displayed in SEO previews
</ParamField>
