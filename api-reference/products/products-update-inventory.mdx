The Update Inventory API allows the user to bulk update the inventory for multiple items. Use this endpoint to update the available quantity and out-of-stock purchase settings for multiple items in the inventory.

```http
POST https://services.leadconnectorhq.com/products/inventory
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField body="altType" type="string" required>
Posibles valores: 'account'
</ParamField>

<ParamField body="items" type="object[]" required>
Array of items to update in the inventory.
<Expandable title="cada item">
<ParamField body="priceId" type="string" required default='5e9f8f8f8f8f8f8f8f8f8f8'>
The unique identifier for the price, in MongoDB ID format.
</ParamField>

<ParamField body="availableQuantity" type="number" default='10'>
The available quantity of the item.
</ParamField>

<ParamField body="allowOutOfStockPurchases" type="boolean" default='False'>
Whether to continue selling the item when out of stock.
</ParamField>

</Expandable>
</ParamField>
