Retrieves detailed information about a specific action using its unique identifier. Returns the action configuration, associated agents, and performance metrics.

```http
GET https://services.leadconnectorhq.com/conversation-ai/agents/{agentId}/actions/{actionId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="actionId" type="string" required>
The unique identifier of the action ID Attached to the agent
</ParamField>

<ParamField path="agentId" type="string" required>
</ParamField>


