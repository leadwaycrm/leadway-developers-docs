---

The "Create Shipping Rate" API allows adding a new shipping rate.

```http
POST https://services.leadconnectorhq.com/store/shipping-zone/{shippingZoneId}/shipping-rate
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="shippingZoneId" type="string" required default='6578278e879ad2646715ba9c'>
ID of the item that needs to be returned
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField body="altType" type="string" required>
Posibles valores: 'account'
</ParamField>

<ParamField body="name" type="string" required default='North zone'>
Name of the shipping zone
</ParamField>

<ParamField body="description" type="string" default='Ships next day'>
Delivery description
</ParamField>

<ParamField body="currency" type="string" required default='USD'>
The currency of the amount of the rate / handling fee
</ParamField>

<ParamField body="amount" type="number" required default='99.99'>
The amount of the shipping rate if it is normal rate (0 means free ). Fixed Handling fee if it is a carrier rate (it will add to the carrier rate).
</ParamField>

<ParamField body="conditionType" type="string" required default='price'>
Type of condition to provide the conditional pricing Posibles valores: 'none', 'price', 'weight'
</ParamField>

<ParamField body="minCondition" type="number" required default='99.99'>
Minimum condition for applying this price. set 0 or null if there is no minimum
</ParamField>

<ParamField body="maxCondition" type="number" required default='99.99'>
Maximum condition for applying this price. set 0 or null if there is no maximum
</ParamField>

<ParamField body="isCarrierRate" type="boolean" default='True'>
is this a carrier rate
</ParamField>

<ParamField body="shippingCarrierId" type="string" required default='655b33a82209e60b6adb87a5'>
Shipping carrier id
</ParamField>

<ParamField body="percentageOfRateFee" type="number" default='10.99'>
Percentage of rate fee if it is a carrier rate.
</ParamField>

<ParamField body="shippingCarrierServices" type="object[]">
An array of items
<Expandable title="cada item">
<ParamField body="name" type="string" required default='Priority Mail Express International'>
Name of the shipping carrier service
</ParamField>

<ParamField body="value" type="string" required default='PriorityMailExpressInternational'>
Value of the shipping carrier service
</ParamField>

</Expandable>
</ParamField>
