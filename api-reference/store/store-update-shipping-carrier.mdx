The "update Shipping Carrier" API allows update a shipping carrier to the system.

```http
PUT https://services.leadconnectorhq.com/store/shipping-carrier/{shippingCarrierId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="shippingCarrierId" type="string" required default='6578278e879ad2646715ba9c'>
ID of the shipping carrier that needs to be returned
</ParamField>

## Body

<ParamField body="altId" type="string" default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField body="altType" type="string">
Posibles valores: 'account'
</ParamField>

<ParamField body="name" type="string" default='FedEx'>
Name of the shipping carrier
</ParamField>

<ParamField body="callbackUrl" type="string" default='https://example.com/get-shipping-rates'>
The URL endpoint that GHL needs to retrieve shipping rates. This must be a public URL.
</ParamField>

<ParamField body="services" type="object[]">
An array of available shipping carrier services
<Expandable title="cada item">
<ParamField body="name" type="string" required default='Priority Mail Express International'>
Name of the shipping carrier service
</ParamField>

<ParamField body="value" type="string" required default='PriorityMailExpressInternational'>
Value of the shipping carrier service
</ParamField>

</Expandable>
</ParamField>

<ParamField body="allowsMultipleServiceSelection" type="boolean" default='True'>
The seller can choose multiple services while creating shipping rates if this is true.
</ParamField>

## Respuestas

<Accordion title="200 - Successful response">
<ResponseField name="status" type="boolean" required default='True'>
Status of api action
</ResponseField>

<ResponseField name="message" type="string" default='Successfully created'>
Success message
</ResponseField>

<ResponseField name="data" type="object" required>

</ResponseField>
