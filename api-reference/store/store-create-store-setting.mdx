title: 'Create/Update Store Settings'
description: 'Create or update store settings by altId and altType.'
---

Create or update store settings by altId and altType.

```http
POST https://services.leadconnectorhq.com/store/store-setting
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField body="altType" type="string" required>
Posibles valores: 'account'
</ParamField>

<ParamField body="shippingOrigin" type="object" required>
Shipping origin address
</ParamField>

<ParamField body="storeOrderNotification" type="object">
Store order notification email
</ParamField>

<ParamField body="storeOrderFulfillmentNotification" type="object">
Store order fulfillment notification email
</ParamField>

## Respuestas

<ResponseField name="status" type="boolean" required default='True'>

<ResponseField name="message" type="string" default='Successfully created'>

</ResponseField>
