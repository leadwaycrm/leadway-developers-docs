Retrieve the list of commissions for a account.

```http
GET https://services.leadconnectorhq.com/affiliate-manager/{locationId}/commissions
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>
