title: 'List Affiliates'
description: 'Retrieve the list of affiliates for a account.'

Retrieve the list of affiliates for a account.

```http
GET https://services.leadconnectorhq.com/affiliate-manager/{locationId}/affiliates
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>
