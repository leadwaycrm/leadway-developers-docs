Get all relations by record Id

```http
GET https://services.leadconnectorhq.com/associations/relations/{recordId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="recordId" type="string" required>
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='clF1LD04GTUKN3b3XuOj'>
Your Sub Account's ID
</ParamField>

<ParamField query="skip" type="number" required default='10'>
</ParamField>

<ParamField query="limit" type="number" required default='100'>
</ParamField>

<ParamField query="associationIds" type="string[]">
Association Ids
</ParamField>
