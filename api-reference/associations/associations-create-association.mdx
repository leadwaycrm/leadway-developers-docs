Allow you to create contact - contact , contact - custom objects associations, will add more in the future.Documentation Link - https://doc.clickup.com/8631005/d/h/87cpx-293776/cd0f4122abc04d3

```http
POST https://services.leadconnectorhq.com/associations/
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='string'>
</ParamField>

<ParamField body="key" type="string" required default='student_teacher'>
Association's Unique key
</ParamField>

<ParamField body="firstObjectLabel" type="object" required default='student'>
First Objects Association Label (custom_objects.children)
</ParamField>

<ParamField body="firstObjectKey" type="object" required default='custom_objects.children'>
First Objects Key
</ParamField>

<ParamField body="secondObjectLabel" type="object" required default='Teacher'>
Second Object Association Label (contact)
</ParamField>

<ParamField body="secondObjectKey" type="object" required default='contact'>
Second Objects Key
</ParamField>
