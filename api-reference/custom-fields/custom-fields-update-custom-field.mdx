```http
PUT https://services.leadconnectorhq.com/custom-fields/{id}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>

<ParamField body="name" type="string" default='Name'>
Field name
</ParamField>

<ParamField body="description" type="string">
Description of the field
</ParamField>

<ParamField body="placeholder" type="string">
Placeholder text for the field
</ParamField>

<ParamField body="showInForms" type="boolean" required>
Whether the field should be shown in forms
</ParamField>

<ParamField body="options" type="object[]">
Options for the field. Important: Providing options will completely replace the existing options array. You must include all existing options alongside any new options you wish to add. Removal of options is not supported through this update. Applicable only for SINGLE_OPTIONS, MULTIPLE_OPTIONS, RADIO, CHECKBOX, TEXTBOX_LIST types.
<Expandable title="cada item">
<ParamField body="key" type="string" required>
Key of the option (Included in Create and Response, excluded in Update)
</ParamField>

<ParamField body="label" type="string" required>
Value of the option
</ParamField>

<ParamField body="url" type="string">
URL associated with the option (Optional, valid only for RADIO type)
</ParamField>

</Expandable>
</ParamField>

<ParamField body="acceptedFormats" type="string">
Allowed file formats for uploads. Options include: .pdf, .docx, .doc, .jpg, .jpeg, .png, .gif, .csv, .xlsx, .xls, all Posibles valores: '.pdf', '.docx', '.doc', '.jpg', '.jpeg', '.png', '.gif', '.csv', '.xlsx', '.xls', 'all'
</ParamField>

<ParamField body="maxFileLimit" type="number" default='2'>
Maximum file limit for uploads. Applicable only for fields with a data type of FILE_UPLOAD.
</ParamField>

<ResponseField name="fieldKey" type="string" required default='custom_object.pet.name'>
Field key. For Custom Object it's formatted as "custom_object.&#123;objectKey&#125;.&#123;fieldKey&#125;". "custom_object" is a fixed prefix, "&#123;objectKey&#125;" is your custom object's identifier, and "&#123;fieldName&#125;" is the unique field name within that object. Example: "custom_object.pet.name" for a "name" field in a "pet" custom object.
</ResponseField>

<ResponseField name="allowCustomOption" type="boolean" default='True'>
Determines if users can add a custom option value different from the predefined options in records for RADIO type fields. A custom value added in one record does not automatically become an option and will not appear as an option for other records.
</ResponseField>
