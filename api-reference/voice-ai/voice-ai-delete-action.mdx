---
title: 'Delete Agent Action'
description: 'Delete an existing action from a voice AI agent. This permanently removes the action and its configuration.'
---

Delete an existing action from a voice AI agent. This permanently removes the action and its configuration.

```http
DELETE https://services.leadconnectorhq.com/voice-ai/actions/{actionId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="actionId" type="string" required>
Unique identifier for the action
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='LOC123456789ABCDEF'>
Account ID
</ParamField>

<ParamField query="agentId" type="string" required>
Agent ID the action is attached to
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X DELETE 'https://services.leadconnectorhq.com/voice-ai/actions/YOUR_actionId' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/voice-ai/actions/YOUR_actionId', {
  method: 'DELETE',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'DELETE',
    'https://services.leadconnectorhq.com/voice-ai/actions/YOUR_actionId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/voice-ai/actions/YOUR_actionId');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
