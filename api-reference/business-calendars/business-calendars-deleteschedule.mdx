title: 'Delete user availability schedule'
description: 'Permanently remove a schedule and all its associated rules. This action cannot be undone.'
---

Permanently remove a schedule and all its associated rules. This action cannot be undone.

```http
DELETE https://services.leadconnectorhq.com/calendars/schedules/{id}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required default='sch123def456ghi789'>
Unique identifier of the schedule to delete
</ParamField>

## Respuestas

<Accordion title="200 - Schedule deleted successfully">
<ResponseField name="success" type="boolean" default='True'>
Whether the deletion was successful
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<Accordion title="400 - Invalid request parameters">
```json
{}
```
</Accordion>

<Accordion title="401 - User not authenticated">
```json
{}
```
</Accordion>

<Accordion title="404 - Schedule with the specified ID was not found">
</Accordion>


## Ejemplo

<CodeGroup>

```bash cURL
curl -X DELETE 'https://services.leadconnectorhq.com/calendars/schedules/YOUR_id' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/calendars/schedules/YOUR_id', {
```

```python Python

        'Version': '2021-07-28',
    },

```

