Get Blocked Slots

```http
GET https://services.leadconnectorhq.com/calendars/blocked-slots
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

<ParamField query="locationId" type="string" required default='0007BWpSzSwfiuSl0tR2'>
Account Id
</ParamField>

<ParamField query="userId" type="string" default='CVokAlI8fgw4WYWoCtQz'>
User Id - Owner of an appointment. Either of userId, groupId or calendarId is required
</ParamField>

<ParamField query="calendarId" type="string" default='BqTwX8QFwXzpegMve9EQ'>
Either of calendarId, userId or groupId is required
</ParamField>

<ParamField query="groupId" type="string" default='ocQHyuzHvysMo5N5VsXc'>

</ParamField>

<ParamField query="startTime" type="string" required default='1680373800000'>
