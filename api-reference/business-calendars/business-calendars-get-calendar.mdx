Get calendar by ID

```http
GET https://services.leadconnectorhq.com/calendars/{calendarId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="calendarId" type="string" required default='ocQHyuzHvysMo5N5VsXc'>
Calendar Id
</ParamField>


```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/calendars/YOUR_calendarId');
```
