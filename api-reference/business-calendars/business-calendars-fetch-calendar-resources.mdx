List calendar resources by resource type and account ID

```http
GET https://services.leadconnectorhq.com/calendars/resources/{resourceType}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="resourceType" type="string" required>
Calendar Resource Type
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required>
</ParamField>

<ParamField query="limit" type="number" required>
</ParamField>

<ParamField query="skip" type="number" required>
</ParamField>
