Associates a calendar with the given schedule by adding the calendarId to a schedule

```http
PUT https://services.leadconnectorhq.com/calendars/schedules/{id}/associations/{calendarId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required default='IkqiJlXJ7o9h61tCHHod'>
Unique identifier of the schedule
</ParamField>

<ParamField path="calendarId" type="string" required default='WvVX9LpvlBO6K506xLbp'>
Unique identifier of the team calendar to add to the schedule
</ParamField>

## Respuestas

<Accordion title="200 - Calendar successfully added to schedule">
<ResponseField name="success" type="boolean" default='True'>
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<Accordion title="400 - Schedule and calendar must belong to the same account">
```json
{}
```
</Accordion>

<Accordion title="401 - User not authenticated">
```json
{}
```
</Accordion>

<Accordion title="404 - Schedule or calendar not found">
```json
{}
```
</Accordion>
