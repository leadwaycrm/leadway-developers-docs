---
title: 'Bulk Delete / Trash Files or Folders'
description: 'Soft-deletes or trashes multiple files and folders in a single request'
---

Soft-deletes or trashes multiple files and folders in a single request

```http
PUT https://services.leadconnectorhq.com/medias/delete-files
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="filesToBeDeleted" type="object[]" required>
Array of file objects to be deleted or trashed
<Expandable title="cada item">
<ParamField body="_id" type="string" required default='686f630df0d3166d68fbcec2'>
Unique identifier of the file or folder to be deleted
</ParamField>

</Expandable>
</ParamField>

<ParamField body="altType" type="string" required default='account'>
Type of entity that owns the files Posibles valores: 'account'
</ParamField>

<ParamField body="altId" type="string" required default='sx6wyHhbFdRXh302LLNR'>
Account identifier
</ParamField>

<ParamField body="status" type="string" required default='deleted'>
Status to set for the files (deleted or trashed) Posibles valores: 'deleted', 'trashed'
</ParamField>

## Respuestas

<Accordion title="200 - Successful response">
```json
[
  {
    "deleted": true,
    "id": "686f630df0d3166d68fbcec2"
  }
]
```
</Accordion>
