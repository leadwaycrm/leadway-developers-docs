Get Surveys

```http
GET https://services.leadconnectorhq.com/surveys/
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
</ParamField>

<ParamField query="skip" type="number">
</ParamField>

<ParamField query="limit" type="number" default='20'>
Limit Per Page records count. will allow maximum up to 50 and default will be 10
</ParamField>

<ParamField query="type" type="string" default='folder'>
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/surveys/' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/surveys/', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/surveys/',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/surveys/');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
