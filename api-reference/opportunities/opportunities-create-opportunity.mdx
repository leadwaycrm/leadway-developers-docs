Create Opportunity

```http
POST https://services.leadconnectorhq.com/opportunities/
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

pipeline Id
</ParamField>

<ParamField body="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
</ParamField>

<ParamField body="name" type="string" required default='First Opps'>
</ParamField>

<ParamField body="pipelineStageId" type="string" default='7915dedc-8f18-44d5-8bc3-77c04e994a10'>
</ParamField>

<ParamField body="status" type="string" required>

</ParamField>
