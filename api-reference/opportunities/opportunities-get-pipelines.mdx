Get Pipelines

```http
GET https://services.leadconnectorhq.com/opportunities/pipelines
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>


```php PHP

$ch = curl_init('https://services.leadconnectorhq.com/opportunities/pipelines');
```
