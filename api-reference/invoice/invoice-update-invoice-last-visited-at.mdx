API to update invoice last visited at by invoice id

```http
PATCH https://services.leadconnectorhq.com/invoices/stats/last-visited-at
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="invoiceId" type="string" required default='6578278e879ad2646715ba9c'>
Invoice Id
</ParamField>
