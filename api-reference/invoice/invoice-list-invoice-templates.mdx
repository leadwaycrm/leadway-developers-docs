API to get list of templates

```http
GET https://services.leadconnectorhq.com/invoices/template
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='6578278e879ad2646715ba9c'>
account Id / company Id based on altType
</ParamField>

<ParamField query="altType" type="string" required default='account'>
Alt Type
</ParamField>

<ParamField query="status" type="string">
status to be filtered
</ParamField>

<ParamField query="startAt" type="string" default='2023-01-01'>
startAt in YYYY-MM-DD format
</ParamField>

<ParamField query="endAt" type="string" default='2023-01-01'>
endAt in YYYY-MM-DD format
</ParamField>

<ParamField query="search" type="string" default='Alex'>
To search for an invoice by id / name / email / phoneNo
</ParamField>

<ParamField query="paymentMode" type="string" default='live'>
payment mode
</ParamField>

<ParamField query="limit" type="string" required default='10'>
Limit the number of items to return
</ParamField>

<ParamField query="offset" type="string" required default='10'>
Number of items to skip
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/invoices/template' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/invoices/template', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/invoices/template',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/invoices/template');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
