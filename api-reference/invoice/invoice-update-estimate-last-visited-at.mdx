API to update estimate last visited at by estimate id

```http
PATCH https://services.leadconnectorhq.com/invoices/estimate/stats/last-visited-at
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="estimateId" type="string" required default='5f9d6d8b1b2d2c001f2d9e4b'>
Estimate Id
</ParamField>
