API to delete an schedule by schedule id

```http
DELETE https://services.leadconnectorhq.com/invoices/schedule/{scheduleId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="scheduleId" type="string" required default='6578278e879ad2646715ba9c'>
Schedule Id
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='6578278e879ad2646715ba9c'>
account Id / company Id based on altType
</ParamField>

<ParamField query="altType" type="string" required default='account'>
Alt Type
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X DELETE 'https://services.leadconnectorhq.com/invoices/schedule/YOUR_scheduleId' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/invoices/schedule/YOUR_scheduleId', {
  method: 'DELETE',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'DELETE',
    'https://services.leadconnectorhq.com/invoices/schedule/YOUR_scheduleId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/invoices/schedule/YOUR_scheduleId');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
