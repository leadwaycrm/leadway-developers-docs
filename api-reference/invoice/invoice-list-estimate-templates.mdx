---

Get a list of estimate templates or a specific template by ID

```http
GET https://services.leadconnectorhq.com/invoices/estimate/template
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='6578278e879ad2646715ba9c'>
Account Id or Agency Id
</ParamField>

<ParamField query="altType" type="string" required>
</ParamField>

<ParamField query="search" type="string" default='Alex'>
To search for an estimate template by id / name
</ParamField>

<ParamField query="limit" type="string" required default='10'>
Limit the number of items to return
</ParamField>

<ParamField query="offset" type="string" required default='10'>
Number of items to skip
</ParamField>

## Respuestas

<Accordion title="200 - Successful response">
<ResponseField name="data" type="string[]" required>
List of estimate templates
</ResponseField>

<ResponseField name="totalCount" type="number" required>
Total number of estimate templates available
</ResponseField>

<ResponseField name="traceId" type="string" required>
Unique identifier for tracing the request
</ResponseField>
