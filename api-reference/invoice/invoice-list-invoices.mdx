API to get list of invoices

```http
GET https://services.leadconnectorhq.com/invoices/
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='6578278e879ad2646715ba9c'>
account Id / company Id based on altType
</ParamField>

<ParamField query="altType" type="string" required default='account'>
Alt Type
</ParamField>

<ParamField query="status" type="string">
status to be filtered
</ParamField>

<ParamField query="startAt" type="string" default='2023-01-01'>
startAt in YYYY-MM-DD format
</ParamField>

<ParamField query="endAt" type="string" default='2023-01-01'>
endAt in YYYY-MM-DD format
</ParamField>

<ParamField query="search" type="string" default='Alex'>
To search for an invoice by id / name / email / phoneNo
</ParamField>

<ParamField query="paymentMode" type="string" default='live'>
payment mode
</ParamField>

<ParamField query="contactId" type="string" default='AmuzcoPBpgKeccNsFlib'>
Contact ID for the invoice
</ParamField>

<ParamField query="limit" type="string" required default='10'>
Limit the number of items to return
</ParamField>

<ParamField query="offset" type="string" required default='10'>
Number of items to skip
</ParamField>

<ParamField query="sortField" type="string" default='issueDate'>
The field on which sorting should be applied
</ParamField>

<ParamField query="sortOrder" type="string" default='descend'>
The order of sort which should be applied for the sortField
</ParamField>

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/invoices/', {
```

```python Python
import os, requests
response = requests.request(

        'Version': '2021-07-28',

)

```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/invoices/');

        'Version: 2021-07-28',

]);
$data = json_decode(curl_exec($ch), true);
```
