title: 'Schedule an schedule invoice'

API to schedule an schedule invoice to start sending to the customer

```http
POST https://services.leadconnectorhq.com/invoices/schedule/{scheduleId}/schedule
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="scheduleId" type="string" required default='6578278e879ad2646715ba9c'>
Schedule Id
</ParamField>

## Body

<ParamField body="altId" type="string" required default='6578278e879ad2646715ba9c'>
account Id / company Id based on altType
</ParamField>

<ParamField body="altType" type="string" required default='account'>
Alt Type Posibles valores: 'account'
</ParamField>

<ParamField body="liveMode" type="boolean" required>
</ParamField>

<ParamField body="autoPayment" type="object">
auto-payment configuration
</ParamField>
