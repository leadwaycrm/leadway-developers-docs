Get the next invoice number for the given account

```http
GET https://services.leadconnectorhq.com/invoices/generate-invoice-number
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required>
Account Id
</ParamField>

<ParamField query="altType" type="string" required>
</ParamField>

<Accordion title="200 - Successful response">
<ResponseField name="invoiceNumber" type="number" default='19'>
