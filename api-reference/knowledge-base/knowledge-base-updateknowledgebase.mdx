---
title: 'Update a knowledge base'
---

```http
PUT https://services.leadconnectorhq.com/knowledge-bases/{id}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required>
</ParamField>

## Body

<ParamField body="name" type="string">
field to update the name of the knowledge base
</ParamField>

<ParamField body="description" type="string">
field to update the description of the knowledge base
</ParamField>

## Respuestas

<Accordion title="200 - Knowledge base updated successfully">
<ResponseField name="success" type="boolean" required>
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<Accordion title="400 - Bad Request">
<ResponseField name="statusCode" type="number" default='400'>
</ResponseField>

<ResponseField name="message" type="string" default='Bad Request'>
</ResponseField>

```json
{
  "statusCode": 400,
  "message": "Bad Request"
}
```
</Accordion>

<Accordion title="401 - Unauthorized">
<ResponseField name="statusCode" type="number" default='401'>
</ResponseField>

<ResponseField name="message" type="string" default='Invalid token: access token is invalid'>
</ResponseField>

<ResponseField name="error" type="string" default='Unauthorized'>
</ResponseField>

```json
{
  "statusCode": 401,
  "message": "Invalid token: access token is invalid",
  "error": "Unauthorized"
}
```
</Accordion>


## Ejemplo

<CodeGroup>

```bash cURL
curl -X PUT 'https://services.leadconnectorhq.com/knowledge-bases/YOUR_id' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "name": "string",
  "description": "string"
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/YOUR_id', {
  method: 'PUT',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({"name": "string", "description": "string"}),
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'PUT',
    'https://services.leadconnectorhq.com/knowledge-bases/YOUR_id',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
        'Content-Type': 'application/json',
    },
    json={"name": "string", "description": "string"},
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/YOUR_id');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'PUT',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode({'name': 'string', 'description': 'string'}),
]);
$data = json_decode(curl_exec($ch), true);
```
