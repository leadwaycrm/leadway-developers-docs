---
title: 'Delete a knowledge base'
---

```http
DELETE https://services.leadconnectorhq.com/knowledge-bases/{knowledgeBaseId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="knowledgeBaseId" type="string" required>
</ParamField>

## Respuestas

<Accordion title="200 - Knowledge base deleted successfully">
<ResponseField name="success" type="boolean" required>
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<Accordion title="400 - Bad Request">
<ResponseField name="statusCode" type="number" default='400'>
</ResponseField>

<ResponseField name="message" type="string" default='Bad Request'>
</ResponseField>

```json
{
  "statusCode": 400,
  "message": "Bad Request"
}
```
</Accordion>

<Accordion title="401 - Unauthorized">
<ResponseField name="statusCode" type="number" default='401'>
</ResponseField>

<ResponseField name="message" type="string" default='Invalid token: access token is invalid'>
</ResponseField>

<ResponseField name="error" type="string" default='Unauthorized'>
</ResponseField>

```json
{
  "statusCode": 401,
  "message": "Invalid token: access token is invalid",
  "error": "Unauthorized"
}
```
</Accordion>


## Ejemplo

<CodeGroup>

```bash cURL
curl -X DELETE 'https://services.leadconnectorhq.com/knowledge-bases/YOUR_knowledgeBaseId' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/YOUR_knowledgeBaseId', {
  method: 'DELETE',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'DELETE',
    'https://services.leadconnectorhq.com/knowledge-bases/YOUR_knowledgeBaseId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/YOUR_knowledgeBaseId');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'DELETE',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```

</CodeGroup>
