---
title: 'Get all trained page links by knowledge base'
---

```http
GET https://services.leadconnectorhq.com/knowledge-bases/crawler
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="knowledgeBaseId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
knowledge base ID as string
</ParamField>

<ParamField query="locationId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
account ID as string
</ParamField>

<ParamField query="page" type="number" default='1'>
Page number
</ParamField>

<ParamField query="pageLength" type="number" default='1'>
Records per page
</ParamField>

<ParamField query="query" type="string" default='www.example.com/'>
query to filter on url links
</ParamField>

## Respuestas

<Accordion title="200 - Trained page links retrieved successfully">
<ResponseField name="count" type="number" required default='64'>
Total count of URLs in the knowledge base
</ResponseField>

<ResponseField name="urls" type="object[]" required>
Array of crawled URLs with their details
<Expandable title="cada item">
<ResponseField name="id" type="string" required default='688c73a25275c513f5f3a7de'>
Unique identifier for the URL
</ResponseField>

<ResponseField name="url" type="string" required default='https://developer.mozilla.org/en-US/blog'>
The actual URL that was crawled
</ResponseField>

<ResponseField name="title" type="string" required default='MDN Blog'>
Title of the webpage
</ResponseField>

<ResponseField name="status" type="string" required default='Successful'>
Current processing status of the URL Posibles valores: 'Pending', 'Processing', 'Successful', 'Failed', 'Existing', 'Restricted', 'Cancelled', 'Aborted', 'Training'
</ResponseField>

<ResponseField name="locationId" type="string" required default='qIyivCmsuEOSnyoFYEej'>
Account ID associated with this URL
</ResponseField>

<ResponseField name="knowledgeBaseId" type="string" required default='Arc9QRauPKkSuMJO8D0m'>
Knowledge base ID this URL belongs to
</ResponseField>

<ResponseField name="content" type="string" required default='https://storage.googleapis.com/crm-conversations-ai-staging/conversationAI/2025/8/1/locations/qIyivCmsuEOSnyoFYEej/688c739c88c89f21ad30f63e-4IseusbZ3vDXMT8WNw9M.txt'>
URL to the stored content file
</ResponseField>

<ResponseField name="contentEditedByUser" type="boolean" required default='False'>
Whether the content was edited by user
</ResponseField>

<ResponseField name="updatedAt" type="string" required default='2025-08-01T07:58:29.858Z'>
Last updated timestamp
</ResponseField>

</Expandable>
</ResponseField>
