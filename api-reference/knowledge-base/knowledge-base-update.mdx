---
title: 'Update an existing knowledge base FAQ'
---

```http
PUT https://services.leadconnectorhq.com/knowledge-bases/faqs/{id}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="id" type="string" required default='710KoEzy793Fxubft0bc'>
faq ID as string
</ParamField>

## Body

<ParamField body="question" type="string" required default='What is the capital of France?'>
faq question as a string
</ParamField>

<ParamField body="answer" type="string" required default='The capital of France is Paris.'>
faq answer as a string
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X PUT 'https://services.leadconnectorhq.com/knowledge-bases/faqs/YOUR_id' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "question": "What is the capital of France?",
  "answer": "The capital of France is Paris."
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/faqs/YOUR_id', {
  method: 'PUT',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({"question": "What is the capital of France?", "answer": "The capital of France is Paris."}),
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'PUT',
    'https://services.leadconnectorhq.com/knowledge-bases/faqs/YOUR_id',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
        'Content-Type': 'application/json',
    },
    json={"question": "What is the capital of France?", "answer": "The capital of France is Paris."},
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/faqs/YOUR_id');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'PUT',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode({'question': 'What is the capital of France?', 'answer': 'The capital of France is Paris.'}),
]);
$data = json_decode(curl_exec($ch), true);
```
