---
title: 'Get crawling status for the latest operation'
---

```http
GET https://services.leadconnectorhq.com/knowledge-bases/crawler/status
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
Account ID as string
</ParamField>

<ParamField query="operationId" type="string" required default='1'>
operation id as string
</ParamField>

<ParamField query="knowledgeBaseId" type="string" required default='jjkkxftgvbhjmn,'>
knowledge base id
</ParamField>

## Respuestas

<Accordion title="200 - Operation status fetched successfully">
<ResponseField name="success" type="boolean" required default='True'>
Indicates if the operation was successful
</ResponseField>

<ResponseField name="data" type="object" required>
Detailed crawling status data
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<Accordion title="400 - Bad Request">
<ResponseField name="statusCode" type="number" default='400'>
</ResponseField>

<ResponseField name="message" type="string" default='Bad Request'>
</ResponseField>

```json
{
  "statusCode": 400,
  "message": "Bad Request"
}
```
</Accordion>

<Accordion title="401 - Unauthorized">
<ResponseField name="statusCode" type="number" default='401'>
</ResponseField>

<ResponseField name="message" type="string" default='Invalid token: access token is invalid'>
</ResponseField>

<ResponseField name="error" type="string" default='Unauthorized'>
</ResponseField>

```json
{
  "statusCode": 401,
  "message": "Invalid token: access token is invalid",
  "error": "Unauthorized"
}
```
</Accordion>

<Accordion title="422 - Unprocessable Entity">
<ResponseField name="statusCode" type="number" default='422'>
</ResponseField>

<ResponseField name="message" type="string[]">
</ResponseField>

<ResponseField name="error" type="string" default='Unprocessable Entity'>
</ResponseField>

```json
{
  "statusCode": 422,
  "message": [
    "Unprocessable Entity"
  ],
  "error": "Unprocessable Entity"
}
```
</Accordion>

<Accordion title="500 - Internal Server Error">
<ResponseField name="statusCode" type="number" default='500'>
</ResponseField>

<ResponseField name="message" type="string" default='Internal Server Error'>
</ResponseField>

```json
{
  "statusCode": 500,
  "message": "Internal Server Error"
}
```
</Accordion>


## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/knowledge-bases/crawler/status' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/crawler/status', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/knowledge-bases/crawler/status',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/crawler/status');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
