---
title: 'Get all knowledge bases for a account by account Id (paginated)'
---

```http
GET https://services.leadconnectorhq.com/knowledge-bases/
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required>
</ParamField>

<ParamField query="query" type="string">
search query for knowledge base name
</ParamField>

<ParamField query="limit" type="number" default='20'>
Maximum number of knowledge bases to return
</ParamField>

<ParamField query="lastKnowledgeBaseId" type="string" default='ZwTB8S0yo0FIBY6OPZTD'>
ID of the last knowledge base from the previous page (for pagination)
</ParamField>

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/knowledge-bases/' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/knowledge-bases/',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
