---
title: 'Train discovered website pages and ingest into the knowledge base'
---

```http
POST https://services.leadconnectorhq.com/knowledge-bases/crawler/train
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
Account ID as string
</ParamField>

<ParamField body="urlIds" type="string[]" required>
List of Object ids of the discovered urls
</ParamField>

<ParamField body="knowledgeBaseId" type="string" required default='jjkkxftgvbhjmn,'>
knowledge base id
</ParamField>

<ParamField body="operationId" type="string" required default='688b640bcb02d498102a13f0,'>
operation id as string
</ParamField>
