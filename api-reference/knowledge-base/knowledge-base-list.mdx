title: 'Get all FAQs by knowledge base with pagination support'

---

Retrieves FAQs for a knowledge base. Supports pagination using limit and lastFaqId parameters.

```http
GET https://services.leadconnectorhq.com/knowledge-bases/faqs
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="knowledgeBaseId" type="string" required default='710KoEzy793Fxubft0bc'>
knowledge base ID as string
</ParamField>

<ParamField query="locationId" type="string" required default='qDZpF8GH3qvgJTmKCoL'>
account ID as string
</ParamField>

<ParamField query="limit" type="number" default='10'>
Limit the number of FAQs returned
</ParamField>

<ParamField query="lastFaqId" type="string" default='3rzeElC1FOVY91veVBkp'>
Last FAQ ID for pagination (cursor-based)
</ParamField>

## Respuestas

<Accordion title="200 - FAQs retrieved successfully">
<ResponseField name="count" type="number" required default='150'>
Total count of all FAQs in the knowledge base
</ResponseField>

<ResponseField name="faqs" type="object[]" required>
Array of FAQ objects
<Expandable title="cada item">
<ResponseField name="id" type="string" required default='3rzeElC1FOVY91veVBkp'>
FAQ ID as string
</ResponseField>

<ResponseField name="question" type="string" required default='What is 1+2?'>
FAQ question
</ResponseField>

</ResponseField>

<ResponseField name="answer" type="string" required default='3'>

</ResponseField>

<ResponseField name="knowledgeBaseId" type="string" required default='I1rITlYLJofFosIqC4Np'>
Knowledge base ID
</ResponseField>

<ResponseField name="locationId" type="string" required default='qIyivCmsuEOSnyoFYEej'>

</ResponseField>

Whether the FAQ is deleted
</ResponseField>

<ResponseField name="createdAt" type="string" required default='2025-08-02T19:47:57.243Z'>
Date when FAQ was created
</ResponseField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/knowledge-bases/faqs' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/faqs', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/knowledge-bases/faqs',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/faqs');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
