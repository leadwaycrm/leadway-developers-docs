---
title: 'Create a new knowledge base (max 15 knowledge bases per account)'
---

```http
POST https://services.leadconnectorhq.com/knowledge-bases/
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="name" type="string" required>
</ParamField>

<ParamField body="description" type="string">
</ParamField>

<ParamField body="locationId" type="string" required>
</ParamField>

## Respuestas

<Accordion title="201 - Knowledge base created successfully">
<ResponseField name="success" type="boolean" required default='True'>
Success status of the operation
</ResponseField>

<ResponseField name="data" type="object" required>
Created knowledge base details
</ResponseField>

```json
{
  "success": true
}
```
</Accordion>

<ResponseField name="statusCode" type="number" default='400'>
</ResponseField>

</ResponseField>

```json
  "statusCode": 400,
  "message": "Bad Request"

```
</Accordion>

<ResponseField name="statusCode" type="number" default='401'>
</ResponseField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X POST 'https://services.leadconnectorhq.com/knowledge-bases/' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28' \
  -H 'Content-Type: application/json' \
  -d '{
  "name": "string",
  "description": "string",
  "locationId": "string"
}'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/knowledge-bases/', {
  method: 'POST',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({"name": "string", "description": "string", "locationId": "string"}),
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'POST',
    'https://services.leadconnectorhq.com/knowledge-bases/',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
        'Content-Type': 'application/json',
    },
    json={"name": "string", "description": "string", "locationId": "string"},
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/knowledge-bases/');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'POST',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
        'Content-Type: application/json',
    ],
    CURLOPT_POSTFIELDS => json_encode({'name': 'string', 'description': 'string', 'locationId': 'string'}),
]);
$data = json_decode(curl_exec($ch), true);
```
