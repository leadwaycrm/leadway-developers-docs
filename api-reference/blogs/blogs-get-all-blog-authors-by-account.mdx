The "Get all authors" Api return the blog authors for a given account ID. Please use "blogs/author.readonly"

```http
GET https://services.leadconnectorhq.com/blogs/authors
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>

<ParamField query="limit" type="number" required default='5'>
Number of authors to show in the listing
</ParamField>

<ParamField query="offset" type="number" required>
Number of authors to skip in listing
</ParamField>
