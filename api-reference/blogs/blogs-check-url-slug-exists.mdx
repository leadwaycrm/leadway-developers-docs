The "Check url slug" API allows check the blog slug validation which is needed before publishing any blog post. Please use blogs/check-slug.readonly. you can find the POST ID from the post edit url.

```http
GET https://services.leadconnectorhq.com/blogs/posts/url-slug-exists
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="urlSlug" type="string" required>
</ParamField>

<ParamField query="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
</ParamField>

<ParamField query="postId" type="string" default='66f429b8afdce84227a4610d'>
</ParamField>

## Respuestas

<Accordion title="200 - Successful response">
<ResponseField name="exists" type="boolean" required>
