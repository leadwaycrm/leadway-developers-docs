The "Get Blogs by Account ID" API allows you get blogs using Account ID.Please use blogs/list.readonly

```http
GET https://services.leadconnectorhq.com/blogs/site/all
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
</ParamField>

<ParamField query="skip" type="number" required>
</ParamField>

<ParamField query="limit" type="number" required default='4'>
</ParamField>

<ParamField query="searchTerm" type="string" default='ai news'>
search for any post by name
</ParamField>

<ResponseField name="data" type="object[]" required>

</ResponseField>

curl -X GET 'https://services.leadconnectorhq.com/blogs/site/all' \

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/blogs/site/all', {
  method: 'GET',
  headers: {

    Version: '2021-07-28',

```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/blogs/site/all',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/blogs/site/all');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
