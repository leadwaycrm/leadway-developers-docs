Get a single link by its ID

```http
GET https://services.leadconnectorhq.com/links/id/{linkId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="linkId" type="string" required>
Link Id
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='ABCHkzuJQ8ZMd4Te84GK'>
Account Id
</ParamField>

## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/links/id/YOUR_linkId' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/links/id/YOUR_linkId', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/links/id/YOUR_linkId',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/links/id/YOUR_linkId');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
