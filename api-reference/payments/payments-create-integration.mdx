API to create a new association for an app and account

```http
POST https://services.leadconnectorhq.com/payments/custom-provider/provider
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='Lk3nlfk4lxlelVEwcW'>
Account id
</ParamField>

## Body

<ParamField body="name" type="string" required default='Company Paypal Integration'>
The name of the custom provider
</ParamField>

<ParamField body="description" type="string" required default='This payment gateway supports payments in India via UPI, Net banking, cards and wallets.'>
Description of payment gateway. Shown on the payments integrations page as subtext
</ParamField>

<ParamField body="paymentsUrl" type="string" required default='https://testpayment.paypal.com'>
This url will be loaded in iFrame to start a payment session.
</ParamField>

<ParamField body="queryUrl" type="string" required default='https://testsubscription.paypal.com'>
The url used for querying payments related events. Ex. verify, refund, subscription etc.
</ParamField>

<ParamField body="imageUrl" type="string" required default='https://testsubscription.paypal.com'>
Public image url for logo of the payment gateway displayed on the payments integrations page.
</ParamField>

<ParamField body="supportsSubscriptionSchedule" type="boolean" required default='True'>
Whether the config supports subscription schedule or not. true represents config supports subscription schedule
</ParamField>
