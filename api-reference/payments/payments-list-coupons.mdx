The "List Coupons" API allows you to retrieve a list of all coupons available in your account. Use this endpoint to view all promotional offers and special discounts for your customers.

```http
GET https://services.leadconnectorhq.com/payments/coupon/list
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Query parameters

<ParamField query="altId" type="string" required default='BQdAwxa0ky1iK2sstLGJ'>
Account Id
</ParamField>

<ParamField query="altType" type="string" required default='account'>
Alt Type
</ParamField>

<ParamField query="limit" type="number" default='10'>
Maximum number of coupons to return
</ParamField>

<ParamField query="offset" type="number" default='0'>
Number of coupons to skip for pagination
</ParamField>

<ParamField query="status" type="string" default='active'>
Filter coupons by status
</ParamField>

<ParamField query="search" type="string" default='DEAL50'>
Search term to filter coupons by name or code
</ParamField>
