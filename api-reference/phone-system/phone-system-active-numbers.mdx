description: 'Retrieve a paginated list of active phone numbers for a specific account. Supports filtering, pagination, and optional exclusion of number pool assignments.'
---

Retrieve a paginated list of active phone numbers for a specific account. Supports filtering, pagination, and optional exclusion of number pool assignments.

```http
GET https://services.leadconnectorhq.com/phone-system/numbers/location/{locationId}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
The unique identifier of the account
</ParamField>

## Query parameters

<ParamField query="pageSize" type="number" default='100'>
How many resources to return in each list page. The default is 50, and the maximum is 1000.
</ParamField>

<ParamField query="page" type="number">
The page index for pagination. The default is 0.
</ParamField>

<ParamField query="searchFilter" type="string" default='+91'>
Filter numbers by phone number pattern. Supports partial matching (e.g., "+91" to find all Indian numbers).
</ParamField>

<ParamField query="skipNumberPool" type="boolean" default='True'>
Whether to exclude numbers that are assigned to number pools. Default is true.
</ParamField>
