Process subscription change initiated by a user (admin/agent). Supports individual custom subscription changes and resub all functionality. Legal forms are automatically created for user-initiated resubscribe actions on custom subscriptions.

```http
POST https://services.leadconnectorhq.com/conversations/preferences/unsubscriptions/user-change
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>

<ParamField body="contactId" type="string" required default='OP7z4LCyPACyH5fcEIZa'>
Contact Id
</ParamField>

<ParamField body="email" type="string" required default='user@example.com'>
Email address
</ParamField>

<ParamField body="subscription_action" type="object" required>
Subscription action details
</ParamField>

<ParamField body="legal_reason" type="string" default='User requested resubscribe via customer service'>
Legal reason for the change (required only for resubscribe and resub_all actions)
</ParamField>

<ParamField body="legal_description" type="string" default='Customer called support on 2024-01-15 requesting to be removed from newsletter'>
Legal description/details
</ParamField>
