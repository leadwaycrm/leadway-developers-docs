Download the recording transcription for a message by passing the message id

```http
GET https://services.leadconnectorhq.com/conversations/locations/{locationId}/messages/{messageId}/transcription/download
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="locationId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
Account ID as string
</ParamField>

<ParamField path="messageId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
Message ID as string
</ParamField>

## Respuestas

<Accordion title="200 - Downloads the attached transcription of the message">
</Accordion>

<Accordion title="400 - Bad Request">
```json
{}
```
</Accordion>

<Accordion title="401 - Unauthorized">
```json
{}
```
</Accordion>


## Ejemplo

<CodeGroup>

```bash cURL
curl -X GET 'https://services.leadconnectorhq.com/conversations/locations/YOUR_locationId/messages/YOUR_messageId/transcription/download' \
  -H 'Authorization: Bearer YOUR_TOKEN' \
  -H 'Version: 2021-07-28'
```

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/conversations/locations/YOUR_locationId/messages/YOUR_messageId/transcription/download', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',
  },
});
const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/conversations/locations/YOUR_locationId/messages/YOUR_messageId/transcription/download',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/conversations/locations/YOUR_locationId/messages/YOUR_messageId/transcription/download');

    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
```
