Set attachments on an existing message (replaces existing). Maximum 5 URLs. Supported for TYPE_CUSTOM_CALL (34) and TYPE_CALL (1) with subType EXTERNAL_CALL.

```http
PUT https://services.leadconnectorhq.com/conversations/messages/{messageId}/attachments
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="messageId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Message Id
</ParamField>

## Body

<ParamField body="attachments" type="string[]" required>
Array of attachment URLs to set on the message (replaces existing). Maximum 5 URLs.
</ParamField>

## Respuestas

<Accordion title="200 - Successfully set message attachments">
</Accordion>

<Accordion title="400 - Bad Request">
```json
{}
```
</Accordion>

<Accordion title="401 - Unauthorized">
```json
{}
```
</Accordion>

<Accordion title="403 - Message type does not support attachment updates">
</Accordion>

<Accordion title="404 - Message not found">
</Accordion>

<CodeGroup>

