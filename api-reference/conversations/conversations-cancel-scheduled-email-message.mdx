Post the messageId for the API to delete a scheduled email message. &lt;br /&gt;

```http
DELETE https://services.leadconnectorhq.com/conversations/messages/email/{emailMessageId}/schedule
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="emailMessageId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Email Message Id
</ParamField>

## Respuestas

<Accordion title="200 - The scheduled email message was cancelled successfully">
<ResponseField name="status" type="number" required default='404'>
HTTP Status code of the request
</ResponseField>

<ResponseField name="message" type="string" required default='Failed cancel the scheduled message'>
Error message of the request
</ResponseField>

```json
{
  "status": 404,
  "message": "Failed cancel the scheduled message"
}
```
</Accordion>

