Get all subscription statuses for a contact (all emails or specific email)

```http
GET https://services.leadconnectorhq.com/conversations/preferences/unsubscriptions/status
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>

<ParamField query="contactId" type="string" required default='OP7z4LCyPACyH5fcEIZa'>
Contact Id
</ParamField>

<ParamField query="email" type="string" default='user@example.com'>
Email address (optional - if not provided, gets all emails for contact)
</ParamField>
