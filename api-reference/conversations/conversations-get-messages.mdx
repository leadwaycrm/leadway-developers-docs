Get messages by conversation id.

```http
GET https://services.leadconnectorhq.com/conversations/{conversationId}/messages
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="conversationId" type="string" required default='tDtDnQdgm2LXpyiqYvZ6'>
Conversation ID as string
</ParamField>

## Query parameters

<ParamField query="lastMessageId" type="string" default='tDtDnQdgm2LXpyiqYvZ6'>
Message ID of the last message in the list as a string
</ParamField>

<ParamField query="limit" type="number" default='20'>
Number of messages to be fetched from the conversation. Default limit is 20
</ParamField>

<ParamField query="type" type="string" default='TYPE_SMS,TYPE_CALL'>
Types of message to fetched separated with comma
</ParamField>

## Respuestas
