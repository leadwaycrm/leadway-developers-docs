**Deprecated endpoint - use GET /agent/:agentId instead.**

Gets a specific agent by its ID for the specified account with all its versions. locationId is required parameter. The agent must have active status.

```http
GET https://services.leadconnectorhq.com/agent-studio/public-api/agents/{agentId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="agentId" type="string" required default='p1q2r3s4t5u6v7w8x9y0z1a2'>
</ParamField>

## Query parameters

<ParamField query="locationId" type="string" required default='C2QujeCh8ZnC7al2InWR'>
</ParamField>

<ParamField query="source" type="string" default='api'>
</ParamField>
