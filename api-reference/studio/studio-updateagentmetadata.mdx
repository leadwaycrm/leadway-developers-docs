Updates agent metadata such as name, description, and status.

```http
PATCH https://services.leadconnectorhq.com/agent-studio/agent/{agentId}
```

## Autorizacion

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticacion](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Version de la API.
</ParamField>

## Path parameters

<ParamField path="agentId" type="string" required default='p1q2r3s4t5u6v7w8x9y0z1a2'>
</ParamField>

## Query parameters

<ParamField query="source" type="string" default='api'>
</ParamField>

## Body

<ParamField body="locationId" type="string" required default='C2QujeCh8ZnC7al2InWR'>
Account ID for authorization (cannot be updated)
</ParamField>

<ParamField body="name" type="string" default='Updated Customer Support Agent'>
Name of the agent
</ParamField>

<ParamField body="description" type="string" default='Updated AI agent with enhanced customer support capabilities'>
Description of the agent
</ParamField>

<ParamField body="status" type="string" default='active'>
Status of the agent Posibles valores: 'active', 'inactive', 'archived'
</ParamField>
