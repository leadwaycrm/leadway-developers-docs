Get Campaigns

curl -X GET 'https://services.leadconnectorhq.com/campaigns/' \

```javascript Node.js
const response = await fetch('https://services.leadconnectorhq.com/campaigns/', {
  method: 'GET',
  headers: {
    Authorization: `Bearer ${process.env.LEADWAY_TOKEN}`,
    Version: '2021-07-28',

const data = await response.json();
```

```python Python
import os, requests
response = requests.request(
    'GET',
    'https://services.leadconnectorhq.com/campaigns/',
    headers={
        'Authorization': f"Bearer {os.environ['LEADWAY_TOKEN']}",
        'Version': '2021-07-28',
    },
)
data = response.json()
```

```php PHP
<?php
$ch = curl_init('https://services.leadconnectorhq.com/campaigns/');
curl_setopt_array($ch, [
    CURLOPT_RETURNTRANSFER => true,
    CURLOPT_CUSTOMREQUEST => 'GET',
    CURLOPT_HTTPHEADER => [
        'Authorization: Bearer ' . getenv('LEADWAY_TOKEN'),
        'Version: 2021-07-28',
    ],
]);
$data = json_decode(curl_exec($ch), true);
```
