---
title: 'Get tags by ids'
---

```http
POST https://services.leadconnectorhq.com/social-media-posting/{locationId}/tags/details
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="locationId" type="string" required default='ve9EPM428h8vShlRW1KT'>
Account Id
</ParamField>

## Body

<ParamField body="tagIds" type="string[]" required>
Array of Tag Ids
</ParamField>
