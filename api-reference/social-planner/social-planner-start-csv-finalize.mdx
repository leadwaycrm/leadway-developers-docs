```http
PATCH https://services.leadconnectorhq.com/social-media-posting/{locationId}/csv/{id}
```

## Autorización

<ParamField header="Authorization" type="string" required>
Bearer token generado desde el portal Leadway. Ver [Autenticación](/authentication).
</ParamField>

<ParamField header="Version" type="string" required default="2021-07-28">
Versión de la API.
</ParamField>

## Path parameters

<ParamField path="locationId" type="string" required default='sdfdsfdsfEWEsdfsdsW32dd'>
</ParamField>

<ParamField path="id" type="string" required default='65f92e55cc884f0d0845e447'>

</ParamField>
